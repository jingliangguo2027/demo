# Agent instructions for research documents

本目录用于保存 Agent 上下文管理系统的调研资料、架构设计、技术方案和讨论结论。

## 核心规则

1. 将本目录中的现有文档视为当前研究事实、架构约束和技术方案的主要依据。
2. 调研、分析、答疑或讨论本身不构成修改文档的授权。
3. 只有当用户明确要求新增、修改、移动、重命名或删除文档时，才可以执行对应操作。
4. 不得因为 Agent 认为某个方案更合理、内容已过时或结构可以优化，就自行修改文档。
5. 未获修改授权时，可以提出建议，但必须在对话中说明，不能写入文件。

## 获得修改授权后

1. 先阅读与任务相关的现有文档，理解当前架构、术语和技术方案。
2. 严格按照用户要求修改，采用满足要求的最小改动范围。
3. 保留原有结论、未决问题、来源信息和不确定性；不得擅自将推测改写为事实。
4. 新内容应与现有术语和目录结构保持一致。如发现冲突，先向用户说明，不自行裁决。
5. 修改完成后，简要列出修改过的文件及主要变化。

## 外部资料

1. 引入飞书、网页、论文或其他外部资料时，保留来源链接和获取日期。
2. 区分原始资料、事实摘录、Agent 分析和用户结论，避免混写。
3. 除非用户明确要求同步或导入，否则读取外部资料后不得自动写入本目录。
