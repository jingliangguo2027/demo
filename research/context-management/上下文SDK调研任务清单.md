# 上下文 SDK 调研任务清单

更新日期：2026-10-03。

以下为本项目建议的研究工作，尚未执行。P0 优先确定契约和正确性，P1 比较质量策略，P2 在已有基线上优化。每项至少输出：问题、候选方案、实验数据、结论与保留的不确定性；不能只摘录论文。

| ID / 优先级 | 任务 | 简单指导 | 预期产出 |
| --- | --- | --- | --- |
| R01 / P0 | 建立评测集与基线 | 先选 20–30 条单 session 任务轨迹，标出必保留要求和原文证据；比较滑动窗口、普通摘要、本方案。能装入窗口的子集另测完整 Raw；长轨迹不使用模型看不到的完整历史作不公平对照。固定任务、模型与预算，留出测试集，多次运行报告波动 | 可回放数据集、评分规则、基线报告 |
| R02 / P0 | 事件与快照契约 | 推演输入中途到达、工具返回乱序、重试、状态更新交错；区分接收顺序、因果关系和模型已见范围 | 数据 schema、消息适配契约、不变量清单 |
| R03 / P0 | 异步交接与崩溃恢复 | 用可控调度注入压缩慢、失败、发布前后崩溃及重复触发；验证覆盖位置、状态、索引不会错位，测实际等待时间 | 状态机、故障测试矩阵、恢复协议 |
| R04 / P0 | Context Builder 预算与排列 | 在同一 token 预算下比较排列、固定/动态分配和历史淘汰策略；保留相同来源候选，避免把召回差异误当作排列收益 | 首版组装策略、预算规则、超限行为 |
| R05 / P0 | Session 清理与信任边界 | 给 Raw、摘要、向量、缓存、作业建立归属清单；测试删除与迟到发布竞态、跨 session 引用及外部指令混入摘要 | 级联删除契约、内容来源规则、隔离与删除测试 |
| R06 / P1 | Episode 分段与触发 | 比较 token、完整交互和语义里程碑边界；测事实跨段损失、压缩延迟和频率，重点处理超长未闭合工具交互 | 分段与触发策略及适用条件 |
| R07 / P1 | 压缩保真与辅助上下文 | 比较无辅助、Rules+State、再加历史摘要；注入错误摘要，观察传播。检查条件、否定、数字、归属和来源引用；人工抽查并做消融 | 压缩提示词、证据 schema、保真报告 |
| R08 / P1 | Current Task State 更新 | 比较规则+patch、主模型结构化输出、独立提取器；连续改需求、任务重开和错误完成判定，测滞后与成本 | 更新策略、状态转移规则、失败处理 |
| R09 / P1 | 两路召回、固定融合与回查 | 首版只用 lexical / BM25 与 semantic / 向量召回，建立固定融合基线，对照单路与两路召回；比较 Episode/命题/TP 的索引粒度，覆盖精确词、当前/历史事实及摘要漏词，检查来源、有效性、去重和预算；模型暂不调权 | 首版检索协议、固定融合配置与版本、原文回退条件及基线报告 |
| R10 / P1 | 轻量 TP 的独立收益与隔离 | 同样预算下比较仅 Episode 与 Episode+轻量 TP；测试功能归属、增量分条摘要、重复触发、变更关系、未压缩 Raw 补查及后台积压 / 失败，验证主循环和 Episode 无等待依赖；完整任务快照仅作为可选研究对照 | 功能关联、增量追加与检索策略，后台隔离及收益成本报告 |
| R11 / P2 | SDK 可接入性与成本 | 用同一核心接入两个不同形态的宿主循环；检查工具消息、token 计数、流式返回、close/reopen；测 p50/p95 延迟、后台积压、缓存收益与总成本 | 最小接入示例、适配器契约、性能报告 |
| R12 / P2 | 检索优化 | 两路固定融合跑通后，再分别验证 Graph、recency、importance 和模型调权；早期五权重方案保留为研究项，不参与首版排序。Graph 检查实体消歧、错误边和索引成本，只有稳定增益才启用 | 相对首版基线的收益成本对照、启用条件与回退开关 |

建议先做 R01–R03 建立可观察的实验骨架，再完成 R04–R05；随后推进 R06–R10，最后评估 R11–R12。R11 的基本接入可提前做小样例，性能优化和复杂适配留到后期。

当前不安排全局记忆、跨 session 用户画像、多租户服务或分布式压缩集群。研究用多个 session 作为独立样本，不等于运行时允许它们共享记忆。

任务完成阈值自学习及根据用户反馈自动调整阈值、触发追问的策略暂不纳入当前调研排期。旧设想仅保留为历史研究内容；待基础流程稳定后另行讨论和安排，不作为现有任务状态判定或轻量 TP 更新的前提。

